# Hierro

App personal de entrenamiento en casa. Dos programas de 5 días, 36 ejercicios
con demostración animada e instrucciones en español, cronómetro de descanso y
registro de series, peso corporal y medidas.

Funciona sin conexión y se instala en el móvil desde el navegador
(**Compartir → Añadir a pantalla de inicio** en iPhone).

El registro se guarda en el navegador de cada dispositivo. Hay un botón para
exportarlo a un archivo.
